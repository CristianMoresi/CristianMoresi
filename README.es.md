### `> ls ~/projects`

| Proyecto | Qué he construido |
| :--- | :--- |
| **[DSPark Studio](https://github.com/CristianMoresi/DSParkStudio)** | **Un DAW para agentes de IA, desarrollado en C++ sobre mi framework DSPark.** Una estación de trabajo local para mezcla, masterización, análisis de audio, composición MIDI y síntesis, controlada mediante **MCP** por Claude, Codex u otros agentes compatibles. Los proyectos editables combinan sintetizadores, samples, efectos, ruteo y automatización; el agente mide, procesa y verifica el audio antes de exportarlo. Disponible para **Windows, macOS y Linux**, gratis para crear contenido personal y comercial. |
| **[DSPark](https://github.com/CristianMoresi/DSPark)** | **Mi framework de audio de código abierto en C++**, desde el motor DSP hasta la infraestructura para crear aplicaciones, efectos e instrumentos. Procesamiento en tiempo real y offline: síntesis, modelado de circuitos analógicos, efectos y análisis musical. **Núcleo header-only sin dependencias externas**, con adaptadores VST3, CLAP y Audio Unit para automatización, MIDI y estado. Documentación y pruebas multiplataforma; **su adaptación a Java es el motor de QuickMaster**. [Documentación ↗](https://cristianmoresi.github.io/DSPark/) |
| **[StyleShift AI](https://styleshiftai.studio)** | **Proyecto musical y plataforma de software creados y gestionados de principio a fin.** Reinterpretaciones y música original con ayuda de IA, respaldadas por un **backend Node.js / PostgreSQL** con API REST, autenticación, webhooks e integraciones con Spotify y YouTube. Me encargo de la producción musical, la automatización y la distribución. El **proyecto musical alcanzó picos de 200.000 oyentes mensuales** en plataformas de streaming. |
| **[QuickMaster](https://github.com/CristianMoresi/QuickMaster)** | **Aplicación de masterización que analiza la canción completa antes de procesarla** para anticipar picos, equilibrar pasajes y calcular compresión, nivelación y clipping a partir del audio. Los controles orientados al resultado mantienen las decisiones creativas en manos del productor. Utiliza **mi adaptación de DSPark a Java**, con EQ, procesamiento estéreo, limitación true peak y exportación por lotes. Portable en **Windows, macOS y Linux**. |
